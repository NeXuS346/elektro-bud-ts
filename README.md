Opis problemu:
W firmie Elektro-Bud potrzebna jest aplikacja,
poprzez którą łatwiejsze stanie się prowadzenie listy produktów znajdujących się na magazynie.
Program umożliwi dodanie nowych produktów, odczyt ich oraz ewentualne usunięcie. 

Wymagania funkcjonalne:
Dodawanie i przeglądanie produktow
walidacja danych (EAN, Sektor, półki)
usuwanie pozycji
czyszczenie formularza po dodaniu produktu
Wyswietlanie kominikatow o bledach w przypadku wpisania nieprawidlowych danych

wymagania niefunkcjonalne:

natychmiastowe dzialanie skryptow
implementacja z uzyciem jezyka TypeScript oraz HTML
dzialanie bezposrednio w przegladarce - brak koniecznosci pobierania oddzielnej aplikacji
przejrzysty, prosty do nawigowania interfejs
